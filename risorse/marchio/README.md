# Risorse del marchio

La cartella contiene il logo a bandiera di ingegnerismo.it nei formati necessari al progetto:

- `logo-ingegnerismo-bandiera.svg`: sorgente vettoriale;
- `logo-ingegnerismo-bandiera.pdf`: versione vettoriale inclusa dal documento LaTeX.

Il PDF deriva direttamente dall'SVG e non deve essere modificato separatamente. In caso di aggiornamento del marchio, si modifica l'SVG e si rigenera il PDF vettoriale.

Palette principale:

- blu: `#006FB9`;
- blu scuro: `#00477A`;
- giallo: `#FFEE84`;
- grigio: `#666665`;
- nero: `#1D1D1B`.
